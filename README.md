# 📰 Новостное SPA-приложение

Одностраничное приложение для просмотра новостей с использованием React, TypeScript и NewsAPI.

## 🛠️ Технологии

- React 18 + TypeScript

- Context API + useReducer (управление состоянием)

- Axios (HTTP-запросы)

- NewsAPI (источник новостей)

- CSS (чистые стили без фреймворков)

## 📦 Установка и запуск

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/ShmaltsIO/WebPractice_TPU.git
```

2. **Перейдите на нужную ветку:**

```bash
git checkout task_5
```

3. **Установите зависимости:**

```bash
npm install
```

4. **Настройте API ключ:**

Получите ключ на NewsAPI.org

Создайте файл .env в корне проекта

Добавьте строку в файл ".env":

```VITE_NEWS_API_KEY=ваш_ключ_здесь```

5. **Запустите приложение:**

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

## 📁 Структура проекта
src/

├── components/     # React-компоненты (карточки, поиск, фильтры)

├── context/       # Контекст приложения

├── services/      # API-сервисы

├── types/         # TypeScript-типы

└── data/          # Моковые данные

## 🔧 Функционал

- Лента новостей с карточками

- Поиск по ключевым словам

- Фильтрация по категориям

- Пагинация "Загрузить еще"

- Загрузка данных из внешнего API

- Индикаторы загрузки

- Адаптивный дизайн

## ⚠️ Важно

NewsAPI на бесплатном тарифе: 100 запросов/день

Для России (country=ru) может возвращать 0 результатов

По умолчанию используются новости из США (country=us)
