# Новостной портал "Static News"

Статическая верстка главной страницы новостного портала с использованием HTML5, CSS3 и JavaScript.

## 🚀 Функциональность

- **Адаптивный дизайн** - сетка новостных карточек меняется с 3 колонок на 1 в зависимости от ширины экрана
- **Семантическая верстка** - использование современных HTML5 тегов
- **Интерактивные элементы**:
  - Плавное подсвечивание карточек при наведении
  - Функция "показать/скрыть" для анонсов новостей
- **Чистая структура** - разделение на header, main, aside и footer

## 🛠 Технологии

- **HTML5** - семантическая разметка
- **CSS3** - Flexbox для адаптивной верстки, плавные переходы
- **JavaScript (ES6)** - работа с DOM, обработка событий
- **Адаптивный дизайн** - мобильная версия

## 🎯 Особенности реализации

### HTML Structure
- `<header>` - логотип и навигационное меню
- `<main>` - секция с новостными карточками
- `<article>` - каждая новостная карточка
- `<aside>` - блок "Топ-5 популярных новостей"
- `<footer>` - копирайт и контактная информация

### CSS Features
- Flexbox для адаптивной сетки
- Плавные переходы (`transition`)
- Эффекты при наведении (`hover`)
- Медиа-запросы для мобильных устройств

### JavaScript Functionality
- Обработчики событий для кнопок
- Динамическое изменение контента
- Плавное появление/скрытие элементов
- Изменение текста кнопок
